# Kinetic Court SD — San Diego : In Play

A pickleball, tennis, padel, squash and ping pong court atlas for San Diego.
Static site, no build step: open `index.html` in a browser.

- `data.js` — all courts, prices, FAQ and links (edit this to change content)
- `app.js` — pages and interactions
- `images/` — photos

Live site: https://kenetic-court-sd.github.io/
